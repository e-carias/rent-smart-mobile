## Cómo tomarlas

- **Web:** con la ventana a 1440 × 900 y el zoom al 100 %. En Chrome,
  `Ctrl/⌘ + Shift + P` → «Capture screenshot» toma la página completa sin el
  navegador alrededor.
- **Móvil:** en el emulador de Android Studio o en Expo Go, con la captura del
  propio dispositivo.

Conviene iniciar sesión con la cuenta de administrador para las pantallas del
panel y con la de cliente para el portal, de modo que cada captura muestre la
interfaz que corresponde a su rol.

## Referenciarlas

Desde el README de la raíz:

```markdown
![Reportes](docs/capturas/web-07-reportes.png)
```

Desde el informe técnico, insertarlas como figuras numeradas con su pie, en el
formato APA 7 que ya usa el documento.
